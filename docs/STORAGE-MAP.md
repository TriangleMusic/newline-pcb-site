## 2. מבנה התיקייה המסודרת

```
NEWLINE-PCB SITE/
├── src/                    ← קוד האתר. כאן עורכים הכל.
│   ├── _data/
│   │   ├── site.json      ← טלפון, מייל, וואטסאפ, כתובת, מפתח הטופס
│   │   └── i18n.js        ← תוויות ניווט/כפתורים בשתי השפות
│   ├── _includes/         ← תבניות משותפות (header, footer, טופס, layouts)
│   ├── assets/
│   │   ├── css/           ← עיצוב
│   │   ├── js/            ← קוד צד-לקוח (טופס, תפריט, גלריה)
│   │   └── img/           ← לוגו, תמונות, גלריות
│   ├── *.njk              ← הדפים באנגלית
│   └── he/*.njk           ← אותם דפים בעברית
├── docs/                   ← כל התיעוד (המסמכים האלה)
│   ├── HANDOVER.md        ← מדריך התחזוקה המלא
│   ├── STORAGE-MAP.md     ← המסמך הזה
│   ├── screenshots/       ← צילומי מסך של האתר (ארכיון ויזואלי)
│   └── dev-logs/          ← לוגים מבדיקות אוטומטיות (לא נדרש לתחזוקה)
├── backups/                ← קובצי ZIP של גיבויים מלאים לפי תאריך
├── .github/workflows/      ← הגדרת הפריסה האוטומטית ל-Cloudflare
├── scripts/                ← סקריפט עזר להורדת תמונות
├── package.json            ← רשימת הכלים שהאתר צריך כדי להיבנות
├── .eleventy.js            ← הגדרות מנוע הבנייה (Eleventy)
├── wrangler.toml           ← הגדרות Cloudflare Pages
└── README.md               ← הסבר טכני קצר באנגלית
```

**תיקיות שנוצרות אוטומטית ולא צריך לגבות:** `node_modules/` (כלים שמותקנים בפקודה `npm install`), `_site/` (תוצר הבנייה).

## 5. איך משחזרים מהגיבוי (קובץ ה-ZIP)

אם GitHub נעלם, המחשב נמחק, או שצריך להעביר את האתר למישהו אחר:

```bash
# 1. פותחים את ה-ZIP לתיקייה חדשה
unzip newline-pcb-site-YYYY-MM-DD.zip -d newline-pcb-site

# 2. מתקינים את הכלים (צריך Node.js 18 ומעלה, מ-https://nodejs.org)
cd newline-pcb-site
npm install

# 3. הרצה מקומית לבדיקה — האתר יעלה בכתובת http://localhost:8080
npm run dev

# 4. בנייה לפרסום — התוצר נוצר בתיקיית _site
npm run build
```

את התוכן של `_site` אפשר להעלות לכל שירות אחסון סטטי (Cloudflare Pages, Netlify, Vercel, או אפילו אחסון רגיל) והאתר יעבוד. **אין בסיס נתונים ואין שרת** — זה אתר סטטי, ולכן קל מאוד לשחזר ולהעביר.
